Let's be honest. "Dictate" was a terrible name. It sounded like a checkbox buried in Settings next to "Enable Smart Quotes." And the icon looked like clip art off a printer driver CD from 2004.

So we staged a coup. Bloodless, unless you count the old icon, which was taken out back and deleted. The app is now called **Dictator**. You talk, it writes down every word, and nobody gets to argue. Your word is law. Mostly. There's still Undo.

Meet the new Supreme Leader: a microphone in an officer's cap, aviator shades, and a mustache you could lose a sandwich in. He's a proper Liquid Glass icon, so on macOS 26 and later he catches the light, goes brooding in dark mode, and changes into his tinted and clear uniforms for state occasions. On older macOS he's flat. Still in charge.

Not a fan of the mustache? This is the only regime in history that takes requests. **Settings → App icon** has six official portraits: Morning Rally, Generalissimo, Night Shift, State Portrait, Olive Branch and Old Regime. Click one and the Dock and app switcher change on the spot. Finder keeps Generalissimo, because macOS won't let an app change its own Finder icon. Apple runs a tighter dictatorship than we do.

Nothing of yours gets purged. Your API key, settings, shortcuts, history and the Accessibility switch all survive the revolution. If you already had the app, the file in Applications stays named Dictate.app after this update, because the updater swaps the new one in right where the old one sat. Rename it in Finder if you want the full experience. Nothing breaks either way.

Dictation itself didn't change. Same mic, same speed, same pill. We spent an entire release on a hat, and we'd do it again.

The short version:

- The app is now called Dictator: menu bar, Dock, window, messages and downloads.
- New app icon, Generalissimo, a Liquid Glass icon with light, dark, tinted and clear looks on macOS 26 and later.
- New: Settings → App icon, with six icons to choose from. The pick shows in the Dock, the app switcher and Settings. Finder keeps the default.
- Your API key, settings, history and Accessibility permission carry over. Nothing to set up.
- A copy installed before this update keeps the Dictate.app file name. Rename it in Finder if you like.
- No changes to dictation, the microphone or the pill.
