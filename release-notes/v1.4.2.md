After every single update, your Mac asked for your login password so Dictate could read its own API key. Every. Damn. Update. Like a bouncer who's seen you a hundred times and still wants ID. And it was our fault for putting the key somewhere that made macOS suspicious.

So we moved the key out of the Keychain and into a private file only your user account can read. No more password prompts. If you had a key saved the old way, it moves over by itself the first time.

The short version:

- The Inworld API key is now stored in a private file instead of the Keychain, so updates no longer ask for your password.
- An existing key moves over on its own.
