You know when you read an activation code out loud? P, E, C, two, six, and so on. You say it like a hostage negotiator, slow and clear. And Dictate, the overachieving little shit, wrote down exactly what it heard: P-E-C-2-6-B-A-4-9-7. Hyphens everywhere. Like it was spelling a word for a toddler who'd just learned the alphabet.

Nobody wants that. The code box doesn't want that. The code box wants PEC26BA497 and it wants it now.

So now Dictate spots a code read out letter by letter and smushes it back together. Activation codes, order numbers, a phone number said one digit at a time, all of it comes out in one clean piece. U-S-A becomes USA. Five, five, five, one, two, three comes out as 5551234. It all happens right on your Mac, no AI involved, and it's faster than you can blink. We checked. We blinked a lot.

It leaves normal sentences alone. "Plan A B" stays "Plan A B." "I need a 5 minute break" stays exactly that, because we're idiots, but not *those* idiots. Dates, version numbers and phone numbers you already wrote with dashes don't get touched either.

If it ever squishes something it shouldn't, turn off **Settings → Join spelled-out codes**, and then come yell at us.
