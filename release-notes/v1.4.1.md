Three fixes walk into a bar.

First fix. The very first time you allowed the microphone, the first dictation would just hang there. Frozen. Like it was waiting for someone to yell "action." Nobody yelled. It doesn't wait anymore.

Second fix. Updates now install themselves once your Mac has had no keyboard or mouse input for three minutes and you're not dictating. So we never restart the app mid-sentence. We wait until you go to the bathroom. We're not animals.

Third fix. If you dictated right after some text, we'd jam it on with no space. "Thanks for the update.Sounds great." Two sentences spooning. Now we add the space first, like decent people.

The short version:

- Fixed the first dictation hanging right after allowing the microphone.
- Downloaded updates install after three idle minutes, never during a dictation.
- A space is added before a dictation that follows other text.
